# CoSTAR Robin Archive Demo

A desktop Unity package containing the Robin voice/archive client, a framed 3D artwork display and a scene builder.

Install this folder's `package.json` through Unity Package Manager, then choose **Tools → CoSTAR → Create Robin Archive Demo**.

See [the Unity handoff guide](../README.md) for running the Surrey services, comparing the two engines, supported platforms and protocol details.

The package contains no model weights, credentials or archive databases. Avara font credits and the OFL licence are in `Resources/Fonts`.
