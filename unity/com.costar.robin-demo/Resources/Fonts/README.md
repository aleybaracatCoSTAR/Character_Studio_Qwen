# Avara Unity fonts

Unmodified OpenType files copied from the user-supplied Avara distribution:

- `fonts/Avara-Black.otf`
- `fonts/Avara-Bold.otf`
- `fonts/Avara-BoldItalic.otf`

The upstream README credits Raphaël Bastide, Wei Huang, Lucas Le Bihan,
Jérémy Landes and Walid Bouchouchi. The original README and FONTLOG are
included here without modification.

The creation notice embedded in all three supplied font files is:

> Created by Raphael Bastide with FontForge 2.0 (http://fontforge.sf.net). Edited by Wei Huang and Lucas Le Bihan

The supplied README and FONTLOG identify the license as SIL Open Font
License 1.1. `OFL-1.1.txt` includes that embedded notice and the official
license body. No copyright dates or Reserved Font Names have been added.

Project: https://raphaelbastide.com/avara

Upstream repository listed in the supplied package:
https://gitlab.com/velvetyne/Avara

Official license text: https://openfontlicense.org/documents/OFL.txt

The Unity scene builder creates TMP font assets from these files for gallery
headings. Body text uses the project's imported TMP sans-serif font. No
external font service is used.
